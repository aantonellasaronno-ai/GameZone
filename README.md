# GameZone - Tienda Gamer

Proyecto escolar de una tienda online ficticia de juegos, consolas, accesorios y merch, creada con HTML, CSS y JavaScript.

## Funciones
- Catálogo de productos con imagen, nombre, categoría, plataforma, precio y valoración.
- Categorías y buscador.
- Filtro por precio y ordenamiento.
- Carrito: agregar, eliminar, cambiar cantidades y calcular total.
- Favoritos.
- Modo claro/oscuro.
- Guardado del carrito y favoritos con localStorage.
- Formulario de contacto y proceso de compra simulados.
- Diseño adaptable a celulares y computadoras.

## Cómo abrir
Abrí `index.html` en un navegador. No necesita instalación.

## Publicar con GitHub Pages
1. Creá un repositorio en GitHub y subí los archivos de esta carpeta.
2. Entrá a Settings > Pages.
3. En Build and deployment elegí Deploy from a branch.
4. Seleccioná `main` y `/root` y guardá.
5. GitHub mostrará el enlace publicado.

## Uso de IA (Vibe Coding)
Se utilizó una herramienta de Inteligencia Artificial para ayudar a diseñar la identidad visual, generar una imagen de referencia, escribir y organizar código HTML, CSS y JavaScript, proponer funcionalidades, y revisar la estructura del proyecto. El alumno debe revisar el código y poder explicar qué hace cada parte.

## Tecnologías
HTML5, CSS3, JavaScript y localStorage.
